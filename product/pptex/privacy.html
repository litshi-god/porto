Kebijakan Privasi PPTEX

Terakhir Diperbarui: 20 Mei 2026

Privasi Anda adalah prioritas utama kami. Aplikasi PPTEX dirancang dengan prinsip dasar bahwa data dan informasi Anda sepenuhnya adalah milik Anda. Kebijakan ini menjelaskan bagaimana kami memperlakukan data Anda saat Anda menggunakan aplikasi desktop PPTEX.

1. Data yang Dikumpulkan

PPTEX adalah aplikasi berbasis lokal. Kami tidak mengumpulkan, menyimpan, atau mentransmisikan data pribadi Anda ke server kami. Tidak ada mekanisme pendaftaran akun, analitik perilaku, atau pelacakan telemetri pengguna di dalam aplikasi.

2. Pengolahan Dokumen Lokal

Saat Anda mengunggah berkas PDF atau DOCX untuk dikonversi menjadi slide:

  • Ekstraksi teks dan gambar dilakukan sepenuhnya secara lokal di komputer Anda.
  • Konten dokumen Anda dikirimkan langsung ke penyedia layanan AI (OpenAI/Groq) melalui API aman untuk memproses outline presentasi.
  • Konten dokumen atau slide Anda tidak pernah dikirim ke LeonXLab atau disimpan di infrastruktur server pihak kami.

3. Keamanan API Key

Aplikasi ini dilengkapi dengan API Key bawaan yang digunakan untuk memproses perintah presentasi. API Key ini dienkripsi dengan metode enkripsi AES-256-CBC pada level biner aplikasi dan didekripsi langsung di memori komputer Anda saat runtime. API Key ini tidak pernah dikirim ke pihak ketiga selain endpoint API OpenAI dan Groq resmi.

4. Berkas Log

Untuk kebutuhan debug dan pemecahan masalah teknis, aplikasi mencatat aktivitas pembuatan presentasi di dalam berkas log lokal di perangkat Anda. Berkas log ini disimpan di folder data aplikasi pengguna (AppData/Roaming pada Windows). Berkas log ini bersifat lokal dan tidak akan pernah dikirimkan ke server kami kecuali jika Anda secara sukarela mengirimkannya untuk kepentingan bantuan teknis.
